  ABSTRACT  (~150-200 words)
================================================================================

  Sentence 1 – Context: Sign language is the primary communication
               tool for hearing-impaired communities, yet automated
               recognition systems remain heavy and data-hungry.
  Sentence 2 – Gap: Low-resource languages such as Azerbaijani Sign
               Language lack both large datasets and lightweight models.
  Sentence 3 – Method: We present a training-free pipeline that
               extracts MediaPipe hand landmarks (21 joints × 3 coords
               × 2 hands = 126D per frame), uniformly samples 64 frames,
               constructs a 64×126 feature matrix, and retrieves the
               closest sentence via cosine similarity.
  Sentence 4 – System: A real-time webcam module auto-detects signing
               onset/offset and returns the top-3 matches.
  Sentence 5 – Results: On 342 Azerbaijani SL videos spanning 80+
               sentences, the system achieves [X]% top-1 and [Y]%
               top-3 accuracy at ≤[Z] ms per query on a CPU.
  Sentence 6 – Significance: The approach requires no GPU, no model
               training, and can be extended with new sentences by
               simply adding reference videos.

  Keywords: Sign Language Recognition · MediaPipe · Hand Landmarks ·
            Cosine Similarity · Real-Time · Azerbaijani Sign Language

  3.1  Frame Extraction & Uniform Sampling
       • Read all frames via OpenCV
       • Uniform sampling: idx_i = ⌊i · T / N⌋, i = 0…N−1
       • If T < N → duplicate; if T > N → stride
       • One equation block for sampling formula

  3.2  Hand Landmark Feature Extraction

  ┌──────────────────────────────────────────────────────────┐
  │  *** FIGURE 2 – MediaPipe 21-Landmark Hand Model ***     │
  │                                                          │
  │  (Use official MediaPipe diagram, ~0.25 page)            │
  │  Show: 21 numbered joints on a hand silhouette           │
  │  Caption: MediaPipe hand landmark topology.              │
  │  21 joints × 3 coordinates (x,y,z) = 63 features/hand.  │
  └──────────────────────────────────────────────────────────┘

       • 21 landmarks × 3 coords × 2 hands = 126 features per frame
       • Wrist-centred normalization:
             c_i = l_i − l_0
             n_i = c_i / max_j ‖c_j‖
       • Zero-pad if hand not detected

  3.3  Feature Matrix & Cosine Similarity

       • Feature matrix: F ∈ ℝ^{N×126}  (one per video)
       • Flatten: f = vec(F) ∈ ℝ^{8064}
       • Cosine similarity:
             sim(a, b) = (a · b) / (‖a‖ · ‖b‖)
       • Per-sentence score = max over all reference videos

  3.4  Real-Time Inference

  ┌──────────────────────────────────────────────────────────┐
  │  *** FIGURE 4 – State Machine Diagram ***                │
  │                                                          │
  │    ┌──────┐  hands    ┌───────────┐  no hands  ┌──────┐ │
  │    │ IDLE │─────────▶│ RECORDING │──────────▶│COOL- │ │
  │    └──────┘           └───────────┘  (2 sec)   │DOWN  │ │
  │       ▲                    ▲                    └──┬───┘ │
  │       │                    │  hands back           │     │
  │       │                    └───────────────────────┘     │
  │       │               timeout elapsed                    │
  │       │◀──── MATCH & DISPLAY TOP-3 ◀────────────────────┘│
  │                                                          │
  │  Caption: State machine for automatic sign segmentation. │
  └──────────────────────────────────────────────────────────┘

       • IDLE: wait for hands
       • RECORDING: collect frames while hands visible
       • COOLDOWN: hands gone → wait 2 s → confirm end
       • MATCHING: trim edges, sample 64 frames, extract features,
         cosine search, display top-3
       • Controls: q = quit, r = reset

  5. CONCLUSION  (~0.3 page)
================================================================================

  DRAFT TEXT:

  This paper presented a lightweight, training-free pipeline for real-time
  Azerbaijani Sign Language sentence recognition. The system extracts
  MediaPipe hand landmarks from uniformly sampled video frames, constructs
  a compact 64×126 feature matrix per video, and retrieves the closest
  matching sentence from a pre-computed database using cosine similarity.
  A webcam-based inference module automatically detects signing onset and
  offset through a four-state machine (IDLE → RECORDING → COOLDOWN →
  MATCHING), returning the top-3 candidate sentences in real time.

  Evaluated on a dataset of 342 videos spanning over 80 Azerbaijani Sign
  Language sentences, the system achieved [X]% top-1 accuracy and [Y]%
  top-3 accuracy with an average query latency of [Z] ms on a standard
  CPU, requiring no GPU or dedicated hardware. The approach is inherently
  extensible: adding a new sentence requires only recording one or more
  reference videos and extracting their feature matrices, with no
  retraining or fine-tuning.

  Several directions remain for future work. First, learning a compact
  embedding space via a small neural network could improve discriminative
  power among visually similar sentences. Second, incorporating body pose
  and facial expression features from MediaPipe Holistic would capture
  non-manual markers that carry grammatical meaning in sign languages.
  Third, expanding the dataset with more signers and sentences would
  strengthen cross-signer generalization. Finally, porting the system to
  a mobile application would bring real-time sign language recognition
  directly to end users.
